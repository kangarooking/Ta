# Windows 版本首个可运行里程碑实施计划

> **供智能体执行：** 按任务逐项实施，每一步使用复选框跟踪；每个任务都必须先写测试、确认失败、完成最小实现，再运行测试与构建。

**目标：** 在不改动现有 macOS 产品的前提下，新增可以在 Windows 10 22H2 与 Windows 11 上运行的「拓」Alpha，完成区域截图、全屏截图、重复上次区域、可配置全局快捷键、自动保存并复制路径、可配置视觉模型、置顶贴图和私密模式主链路。

**架构：** 新增独立 `windows/` 解决方案，使用 WPF 承载 Windows 原生界面，平台能力通过窄接口隔离在 `Ta.Windows.Platform`，可测试的任务状态、文件命名、剪贴板提交策略与结果模型放在 `Ta.Windows.Core`。macOS Swift Package 保持原样；两个平台共享产品语义和 Agent 协议，但不强行共享系统 API 实现。

**技术栈：** .NET SDK 8.0.424、C# 12、WPF、Win32 P/Invoke、GDI 捕获、OpenAI 兼容视觉 API、Windows Credential Manager、xUnit、Git Bash 自动化脚本。

## 全局约束

- 最低系统为 Windows 10 22H2（内部版本 19045），同时支持 Windows 11。
- 普通截图、贴图和导出离线完成，不在后台持续录屏；只有智能识图主动调用配置中的云端模型。
- 私密模式不自动保存、不写剪贴板、不进入最近结果、不调用云端。
- API Key 不进入源码、配置、日志或测试；后续云模型里程碑使用 Windows Credential Manager。
- 所有错误必须说明发生了什么、当前结果是否安全以及用户下一步能做什么。
- 不删除、不覆盖现有 Swift/macOS 功能；Windows 代码只新增在 `windows/`，仓库公共文档仅追加说明。
- 界面不使用 Emoji；交互控件放在标题下方左侧；提示使用站内窗口而非浏览器或系统脚本弹窗。
- 业务提示词不得硬编码；视觉任务指令必须存入可编辑设置。

## 用户追加决策

- 区域截图默认快捷键改为 `Shift+A`，四组快捷键均可在设置页修改并安全回滚冲突配置。
- 截图默认保存到 `%TEMP%\Ta\captures` 并把完整 PNG 路径复制到剪贴板。
- 结果窗口默认不显示，自动保存后立即释放位图；需要时可在设置中开启。
- 不使用 Windows OCR；直接调用设置页中的 Base URL、API Key 与模型名称。
- 首次启动从 `claude-vision-skill/.env` 导入三要素，API Key 只写入 Windows Credential Manager。
- 默认发布框架依赖轻量单文件版，嵌入 ICO 与默认设置后实测约 521KB；关闭主界面进入托盘后主动归还空闲工作集。

## 自检结论

- 需求覆盖：当前计划覆盖 Windows Alpha 的截图、自动保存、路径剪贴板、可配置快捷键、视觉模型、可选结果页、贴图与私密模式；长截图、标注、历史与 Agent Bridge 已明确拆为后续可测试里程碑。
- 占位检查：计划中没有用未定义占位实现冒充完成；WebP 明确采用运行时编码器能力探测，当前阶段不伪造支持。
- 类型一致性：所有平台接口都使用 `CaptureArea` 物理像素坐标、`Guid` 任务 ID 和 `CaptureResult` 传递结果，跨任务签名一致。
