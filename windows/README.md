# 拓 · Ta Windows Alpha

这里是独立的 Windows 原生实现，不修改或替换现有 macOS Swift 版本。

## 当前可用能力

- 区域截图、整个虚拟桌面截图、重复上一次区域；
- 当前前台软件窗口一键截图，无需拖动选区；
- 多显示器负坐标与 Per-Monitor-V2 DPI 感知基础；
- 可自定义全局快捷键，区域截图默认 `Shift+A`；
- 截图自动保存到临时目录并复制完整文件路径；
- 应用启动默认显示主界面，关闭按钮会隐藏到系统托盘；
- 结果窗口默认显示，也可在设置中关闭；关闭时只保留自动保存的文件；
- Base URL、API Key、模型名称可编辑的 AI 视觉识图；
- API Key 加密保存到 Windows Credential Manager；
- 系统托盘与统一私密模式；
- 原子剪贴板保护，迟到任务和用户新复制内容不会被覆盖；
- PNG、JPEG 保存和桌面置顶贴图；
- GDI 捕获 50MP 安全上限，不在后台持续录屏。

当前未完成窗口吸附、延时捕获、长截图、标注、美化、历史、Agent Bridge、WebP 导出、签名安装包和自动更新。未完成能力不会在界面中冒充可用。

## 系统要求

- Windows 10 22H2（内部版本 19045）或 Windows 11；
- 开发环境使用 .NET SDK 8.0.424；
- 默认轻量版依赖共享的 .NET 8 Desktop Runtime；本机已经满足。

## 全自动构建

在仓库根目录使用 Git Bash：

```bash
./windows/scripts/build-windows.sh
```

脚本会自动检查并安装 .NET 8 SDK、还原依赖、运行测试，并生成约 521KB 的框架依赖轻量版。确实需要在没有 .NET 运行时的电脑使用时，可执行 `./windows/scripts/build-windows.sh --self-contained` 生成较大的自包含版。

## 测试

```bash
./windows/scripts/run-tests.sh
./windows/scripts/run-tests.sh --live
./windows/scripts/run-tests.sh --vision-live
```

普通测试不会读取桌面或联网。`--live` 会自动启动测试实例并读取一小块当前桌面像素；`--vision-live` 会把程序生成的 `HELLO 2026` 测试图片发送到设置中的视觉模型。两类测试分开执行，不把未运行的实测伪装成通过。

## 默认快捷键

| 功能 | 快捷键 |
|---|---|
| 智能识图 | `Ctrl+Alt+Shift+1` |
| 区域截图 | `Shift+A` |
| 当前软件窗口截图 | `Shift+W` |
| 全屏截图 | `Ctrl+Alt+Shift+3` |
| 重复区域 | `Ctrl+Alt+Shift+4` |

设置页可直接修改四组快捷键。若组合已被其他程序占用或重复使用，应用会恢复修改前的有效快捷键。

## 隐私与安全

- 普通截图、保存、路径复制和贴图全部在本机完成；
- 只有主动触发“智能识图”才把当前选区的压缩副本发送到设置中的视觉 API；
- Base URL 与模型保存在用户设置，API Key 只进入 Windows Credential Manager；
- 私密模式禁止自动保存、复制路径、云端识图和最近结果留存；
- 选择层按 Esc 取消时不截图、不保存、不修改剪贴板；
- 运行期间如果用户复制了其他内容，自动结果不会覆盖新剪贴板。

## 体积与内存实测

- 轻量单文件：约 521KB；
- 主界面关闭并进入托盘后会主动归还空闲工作集；此前优化基线约 29.6MB，具体数值随系统运行时与窗口状态变化；
- 截图及视觉请求期间会短暂升高，保存完成后位图会释放并归还空闲工作集；
- 关闭结果窗口时不会在内存中保留整张截图，需要再次处理时直接使用剪贴板中的文件路径。
